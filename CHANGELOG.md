# Changelog

## 1.0.1

- **Date and time** at the bottom of the sidebar.
- **Page help.** Hover the **?** next to any page title to see what the page is for, with a link to the matching Telnyx Edge Compute docs.
- **Help column** on the right of every page and tab, explaining each column, card and action. Collapse it with the button at its top; the choice is remembered.

Upgrading from 1.0.0 keeps your profiles, vaults and saved sign-ins. Nothing changes in how they are stored.

## 1.0.0

First release: Mac and Windows apps and the web version, with multiple profiles, functions, actors, secrets, API key bindings, custom domains, SQL databases, KV namespaces, the API explorer and background jobs.
